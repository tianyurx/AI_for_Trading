# 创业公司是怎么找到方向的

2026-11-20 · 接着前三份研究写。做法是把前面看过的公司逐一归类"方向是怎么来的"，再对照两项学术研究。起源故事来自公开报道，出处见文末。

## 先说结论

1. **方向很少是想出来的，多数是做着别的事时被需求拉过去的。** 下面 20 家公司里，9 家是在做的过程中换了方向、换了客户或换了重点。
2. **"被拉过去"的信号很具体**：目标之外的人主动找上门；随手做的东西被意外大量使用；某一小群用户用得特别狠。
3. **懂行的人更容易看见方向。** 最成功的那批创业者平均 45 岁；高成长公司的想法多数来自创始人上一份工作里见过的东西。
4. **转向的直接原因几乎都是和潜在客户说话**，不是分析。
5. **现在和过去的区别只有一个：试一个想法便宜了。** 但"有没有人真的要"仍然只能靠接触真人来回答。

## 一、20 家公司的方向是怎么来的

| 公司 | 一开始在做什么 | 方向是怎么来的 |
| --- | --- | --- |
| Cursor | 给机械设计软件做 AI 助手 | 自己不是机械工程师，不懂那个行业；转去做自己每天在用的代码编辑器 |
| Lovable | 创始人另有一家公司，业余发了一个开源小工具 | 小工具在 GitHub 上爆红，但只有程序员会用；于是做了给普通人用的网页版 |
| Avoca | 给餐馆做 AI 接电话 | 在一次餐饮业会议上，一家暖通公司主动找上门；替这一家做了三个月，然后整个转过去 |
| Granola | 想用大模型重做"思考和工作的工具" | 到处问人"你的工作里什么最烦"，答案是开完会之后的整理 |
| Wiz | 另一个完全不同的安全产品 | 疫情封锁期间挨个找企业安全负责人聊，发现他们都在往云上搬 |
| Plaud | 一个录音硬件 | 发现用得最狠的是医生、律师、销售，于是专门为这些场景做模板 |
| CoreWeave | 用显卡挖以太坊 | 挖矿不行了，有人愿意租这些显卡跑 AI |
| Monster | 卖果汁和天然汽水 | 接手十年后推出能量饮料，换了一门生意 |
| 拼多多 | 水果拼团 | 拼团的玩法比水果本身更有价值，合并成电商平台 |
| Harvey | AI 研究员在想做什么助手 | 当律师的室友说：为什么不做个法律助手 |
| Veeva | 创始人在 Salesforce 做技术高管 | 看到通用的客户管理软件满足不了药企 |
| Fortinet | 创始人做过上一家防火墙公司 | 知道上一代产品哪里不够快 |
| Anthropic | 创始团队在 OpenAI 做研究 | 对同一件事该怎么做有不同看法 |
| DeepSeek | 量化基金内部的 AI 研究 | 基金决定把这部分独立出来 |
| Airbnb | 付不起房租 | 把自己公寓的床垫租给来开会的人 |
| Lululemon | 创始人做过冲浪和滑雪服装 | 去上瑜伽课，发现没有合适的衣服 |
| Meta | 大学生 | 做了自己学校要用的东西 |
| Wingstop | 创始人开披萨连锁 | 看到只卖鸡翅的店也能成立 |
| Anduril | 创始人卖掉了上一家公司 | 认为国防装备的研发方式可以换一种 |
| Nvidia | 给游戏做显卡 | 把显卡开放给科研计算，十多年后成了主业 |

前 9 家（Cursor 到拼多多）都是在做的过程中换了方向、换了客户或换了重点。中间 5 家（Harvey 到 DeepSeek）的方向来自创始人或身边人的本职工作。

## 二、"被拉过去"长什么样

三种信号，都是别人的行为，不是自己的判断：

- **目标之外的人主动找上门。** Avoca 没有去找暖通公司，是对方在餐饮会议上找到他们的。
- **随手做的东西被意外使用。** Lovable 的开源工具拿到五万多颗星，创始人当时的主业是另一家公司。
- **一小群人用得特别狠。** Plaud 的重度用户集中在几个职业；Granola 的用户都在用它整理会议。

反过来，Cursor 放弃第一个方向的理由是：他们不懂那个行业的工作方式、痛点和账怎么算。

## 三、为什么懂行的人更容易看见

- **年龄。** 一项覆盖 270 万名创业者的研究发现，增长最快的千分之一新公司，创始人创业时的平均年龄是 45.0 岁；全体创业者平均 41.9 岁。在高科技行业和创业聚集区，结论大致相同。
- **想法的来源。** 另一项对美国 500 家增长最快的私营公司的研究发现，这些公司起步时往往没有清晰的创新，创始人用的是在上一份工作里见过的想法，照搬或稍作修改。其中 41% 起步时没有商业计划，只有 5% 拿过风险投资。
- **二次创业。** 上表里 Fortinet、Wiz、Granola、Plaud、Anduril 的创始人都不是第一次创业。Plaud 的创始人前三次都失败了。

## 四、转向是怎么发生的

每一次转向的前面，都有一段和真人接触的时间：

- Wiz 用封锁期和一个个安全负责人通话。提醒他们"产品方向不对"的，是团队里一位早期产品经理。
- Granola 的两位创始人到处问同一个问题：你的工作里什么最烦。
- Avoca 给一家客户贴身做了三个月。
- Harvey 的两位创始人直接写信给 OpenAI 的负责人，约到了见面。

没有一个是靠市场分析转过去的。

## 五、现在有什么不同

试一个想法的成本降了很多，所以有人同时试很多个：有独立开发者一个人维护一百多个小工具。但上面的转向没有一次是因为"做得快"，都是因为"有人要"。做得快只是让你能更早把东西放到人面前。

## 局限

- **样本是我挑的成功公司。** 同样一路转向、最后没找到方向的公司不在表里。
- **起源故事多来自创始人事后的讲述**，会被整理得比实际更顺。
- **"45 岁"那项研究讲的是平均值**，不代表年轻人不行；它关于行业经验的具体结论，我这次没有查到原文。
- **关于 YC 公司转向比例的说法**（四分之三在路演前转向等）只在博客里见到，没有可靠出处，这里没有采用。
- 表里 Nvidia、Meta、Lululemon、Wingstop、Anthropic、Anduril 的"方向来源"一栏是我根据前几份研究里的事实概括的，这次没有另找出处。
