# 股东盈余筛选（Owner Earnings Screen）

把巴菲特 1973 年给《华盛顿邮报》估值的四步法，批量套到美股市值前 2000 名上：
先判断每家公司适不适用这套方法，适用的算出估值区间，再按“价格相对保守价值的折扣”排序。

它是筛选器，不是估值机：能量化的部分全部自动算，需要判断的部分（护城河是否真实、
利润率能否修复）只给出代理指标和标记，留给人看。

## 运行

```bash
python -m owner_earnings_screen fetch                 # 下载并缓存数据（约 20 分钟，主要是代码对照表）
python -m owner_earnings_screen screen --rate 0.05103 --asof 2026-11-12
python -m unittest discover -s owner_earnings_screen/tests -t .
```

依赖只有 `pandas` 和 `requests`。输出在 `results/<日期>/`：`screen.csv`（全部 2000 行、
全部指标）和 `report.md`（汇总与名单）。下载缓存在 `data/`，不入库。

`--rate` 是 10 年期美债收益率，需要手工给（默认值写在 `config.py` 里并标了日期）。

## 数据

| 用途 | 来源 | 说明 |
| --- | --- | --- |
| 股票池、价格、市值、行业 | Nasdaq 上市清单接口 | 剔除优先股、票据、权证、单位；多股份类别合并为一家 |
| 财报 | SEC XBRL frames 接口 | 一个科目一年一次请求，返回全部申报公司；取 2014–2026 |
| 代码↔公司、SIC 行业、财年截止月 | SEC submissions 接口 | 每家公司一次请求 |

只覆盖按美国会计准则、以美元披露的公司。按 IFRS 或本币披露的外国发行人归入“未覆盖”。

## 四步法怎么落地

记 r 为 10 年期美债收益率，各项取最近三个财年的平均。

| 步骤 | 1973 年原版 | 这里的做法 |
| --- | --- | --- |
| 1 股东盈余 | 净利润 + 折旧摊销 − 资本开支，再除以 r | 相同。全部资本开支都当作维持性开支，这是最保守的口径 |
| 2 资本开支≈折旧 | 净利润 ÷ r | 相同 |
| 3 提价能力 | 折现率下调 3 个点到 3.81% | 只对通过“特许经营”代理条件的公司下调，且折现率不低于 3.81% |
| 4 利润率修复 | 税前利润率 10% → 历史均值 15% | 乘以（自身十年中位利润率 ÷ 近三年利润率），限制在 0.5–1.5 倍，双向生效 |

**保守价值** = min（第 1 步，第 2 步，利润率高于常态时按常态下调后的第 2 步）。
它不含增长，也不含利润率修复，候选名单按“市值 ÷ 保守价值”排序。

**乐观价值** = 四步中的最大值。两者之间就是这家公司的估值区间。

**隐含永续增速** = r − 保守口径的股东盈余 ÷ 市值。为负，说明价格低于零增长价值，
这正是 1973 年邮报的情形（约 −6%）。

第 3 步不能照搬的原因：6.81% 减 3 个点，倍数从 14.7 倍变成 26 倍；同样减 3 个点，
放在 5% 的收益率上是 50 倍。所以这里把折现率的下限锁在原版用过的 3.81%。

## 哪些公司不适用

按顺序判断，命中即归类：

| 类别 | 判断依据 |
| --- | --- |
| 外国发行人 / 无数据 | 在 SEC 美元口径数据里匹配不到 |
| 基金、SPAC | SIC 6770、6726 等 |
| 银行、保险、券商 | SIC 6000–6199、6211、6300–6399；或保费收入 ≥ 收入的 30% |
| REIT | SIC 6798 |
| 年报过期 | 最新财年早于 2025-08 |
| 历史不足 | 少于 5 个财年 |
| 亏损 | 近三年平均净利润 ≤ 0 |
| 缺数据 | 资本开支用了自定义科目且不是轻资产公司；或没有收入、税前利润可供核对净利润 |
| 利润为正、股东盈余为负 | 第 1 步结果 ≤ 0，即“低市盈率陷阱” |
| 可估值 | 其余 |

## 标记

- **特许**（第 3 步的代理条件）：至少 8 年记录且年年盈利；ROE 十年中位数 ≥ 15%；
  利润率最低的年份不低于常态的一半；自由现金流/净利润 ≥ 0.6；不属于周期行业。
- **喜诗式**：ROE 中位数 ≥ 20%，年年盈利，资本开支 ≤ 净利润的 40%，分红加回购 ≥ 净利润的 70%，利润仍在增长。
- **周期**：能源、材料、航运、房屋建筑、汽车、半导体等（按 SIC 和 Nasdaq 行业）。
- **质量门槛**（进候选名单的条件）：至少 7 年记录，十年中至少 8 年盈利，
  自由现金流/净利润 ≥ 0.5，利息保障倍数不低于 3，且没有下面两个存疑标记。
- **股本变动**（`share_mismatch`）：清单市值与“股价 × 年报股数”相差超过 0.7–1.4 倍，
  说明年报之后发生过并购、分拆或拆股，历史利润可能对不上现在的公司。
- **存疑**（`suspect`）：市盈率低于 2，按数据错误处理。

## 数据清洗

原始数据直接用会出错，下面每一条都对应一个实际遇到的问题：

1. **净利润被代理声明污染**：接口返回的是“最新申报”的值，而代理声明里的“薪酬与业绩”表会
   重新标注净利润，常把千元、百万元当成元，或者用含少数股东的合并口径。处理办法：
   先用合并净利润、税前利润做参照，差 10³ 或 10⁶ 倍时还原（全市场 187 家公司受影响，
   其中 48 家在前 2000 名内）；再在“净利润”“归属普通股股东净利润”“合并净利润 − 少数股东损益”
   三个读数里取最小值。
2. **一次性收益**：单年净利润超过税前利润 85% 的部分剔除（税收返还、终止经营的出售收益）。
3. **少数股东**：净利润是归母口径，折旧和资本开支是 100% 合并口径，后两者按归母比例折算。
4. **科目取错**：收入、折旧、资本开支各有多个常用科目，公司常把子项标在其中一个上，
   这三项取各科目中的最大值。
5. **滚动十二个月数据**：部分公司在季报里披露滚动年度现金流，会混进年度数据。
   按公司自己历史上最常见的财年截止月过滤（SEC 提供的财年截止字段错误太多，不能用）。
6. **缺口**：折旧缺失按 0 计（低估股东盈余）；资本开支个别年份缺失用已披露年份的均值；
   资本开支完全缺失时，轻资产公司（折旧 < 净利润的 15%）按折旧计，其余不估值。
7. **无法核对的利润**：没有收入、也没有税前或营业利润的公司不估值
   （例如控股型合伙企业，其净利润读数可能来自子公司）。
8. **重组换壳**：新控股公司上市、旧主体保留财报历史时，按公司名把两者对上（如埃克森美孚）。
9. **保险公司**：SIC 代码会把部分保险公司归为“保险经纪”，改用保费收入占比识别。

**核对结果**：候选名单前 100 名、最近三个财年共 300 个净利润读数，逐一与公司 10-K 原值比对，
2 处不一致（一处相差 3%，一处是 10-K 净利润含终止经营亏损而读数不含）。
随机抽取的三只股票价格与券商行情一致。

**时点**：Nasdaq 清单给的是前一交易日收盘价，所以本次结果的价格和利率都取 2026-11-12。

## 局限

- 只是筛选。护城河、管理层、行业前景、会计质量都没有看。
- 三年平均会高估正在衰退的公司，低估正在成长的公司。
- 全部资本开支都算维持性开支，对正在大举扩张的公司偏严。
- 利润率修复用的是公司自己的历史，分不清“暂时受挫”和“永久恶化”。
- 没有负债调整：估值对象是股权，高杠杆只通过利息保障倍数这一道门槛过滤。
- 并购、分拆之后，历史财报对不上现在的公司；`share_mismatch` 只能抓到其中一部分。
- 没有回测。这套排序在历史上是否有效，目前不知道。
